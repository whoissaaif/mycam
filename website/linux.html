MyCam on Linux.

One command installs MyCam on Ubuntu 24.04 and other Debian-based distributions. Your phone then shows up as a camera called MyCam in Zoom, OBS, Discord and browsers.

1. Install

Open a terminal and run:

wget -qO- https://mycam.dev/install.sh | sh

It downloads MyCam v@@VERSION@@, installs it (asking for your password), and starts MyCam and its tray icon. With curl instead: curl -fsSL https://mycam.dev/install.sh | sh. Want to read the script first? It's on GitHub.

Or by hand: download the .deb@@DEB_SIZE@@, then run sudo apt install ./mycam_@@VERSION@@_amd64.deb.

If the install says v4l2loopback is missing, run sudo apt install v4l2loopback-dkms and reboot once. MyCam starts by itself every time you log in.

2. Connect your phone

  • Android over Wi-Fi: install the Android app, keep the phone on the same network as the PC, open MyCam on the phone, tap Find Devices, and tap your PC. Check that both screens show the same 6-digit code, then allow it on both. After that they reconnect by themselves.
  • Android over USB: plug the phone in, open MyCam on the phone and tap USB Connection.
  • iPhone or iPad: click the MyCam tray icon → Connect an iPhone… and scan the QR code with the iPhone's camera (or run mycam-companion --pair in a terminal).

3. Use it as a webcam

Choose MyCam as the camera in any app. The phone's camera only runs while an app is using it. The tray icon has pause, front or back camera, quality, mirror, fill, and the other everyday controls.

Requirements

  • Ubuntu 24.04, Debian, Linux Mint, Pop!_OS or another distribution with apt, on a 64-bit Intel or AMD PC.
  • The v4l2loopback kernel module (installed with MyCam). With Secure Boot on, Ubuntu may ask you to enrol a key for it on the next reboot.
  • For the tray icon on GNOME: the AppIndicator extension, which Ubuntu turns on by default.

If something doesn't work

  • No MyCam camera in apps: reboot once after installing, so the camera module loads.
  • The phone doesn't find the PC: both must be on the same network, and some guest or office networks keep devices apart.
  • No tray icon: run mycam-tray &, or install "AppIndicator and KStatusNotifierItem Support" on other GNOME desktops.
  • More in the Linux guide, or email support@mycam.dev.

Remove MyCam

sudo apt remove mycam

Linux is a beta: Android on Linux has had less testing than on Windows, and there's no settings window yet. Please tell us what works and what doesn't.
