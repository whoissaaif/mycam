01 / Setup

Get started.
Ten minutes, once.

Install on the PC, connect the phone, pick MyCam in your app. After the first time, plugging in is the whole process.

1. Install on Windows

MyCam needs Windows 11. It uses a Windows 11 API for virtual cameras, so Windows 10 won't work.

  1. Download MyCam-Setup-1.4.3.exe (12.1 MB).
  2. Windows will say "Windows protected your PC" because the installer isn't signed yet. Click More info, then Run anyway. You can check the download's SHA-256 against the hash on the home page first.
  3. Run through the installer. It registers the MyCam camera, installs the UsbDk driver if it isn't already present, and adds a firewall rule for the iPhone page on private networks.
  4. MyCam appears in the system tray. Left-click for the window, right-click for the quick menu.

Windows 11 N editions: install Microsoft's Media Feature Pack first. N editions ship without the media components MyCam needs to decode video.

2a. Android over USB

No Developer Options, no USB debugging, no ADB.

  1. Install the MyCam app on the phone. The APK is on the release page.
  2. Plug the phone into the PC.
  3. The phone asks whether to open MyCam. Tick Always and tap OK, then allow camera access.
  4. Windows asks for admin once per new phone, to give the phone's accessory mode its built-in driver.
  5. In any app, choose MyCam as the camera.

While MyCam is running, any Android phone you plug in switches to webcam mode, so file transfer isn't available at the same time. Exit MyCam from the tray to move files.

2b. Android over Wi-Fi

  1. Put the phone and the PC on the same network.
  2. On the PC, open MyCam and choose Generate QR.
  3. In the phone app, scan the code. It pairs and connects — there's no code to compare and nothing to set to Private.
  4. Both screens say Paired with …, and the camera follows.

A phone on the cable always wins over a wireless one. Pairings are remembered, so the phone reconnects by itself next time.

2c. iPhone or iPad

Nothing to install. The PC serves a page and Safari opens it.

  1. Put the iPhone and the PC on the same network, and make sure Windows calls that network Private — the firewall rule is private-only.
  2. On the PC, open MyCam and choose Connect an iPhone. A QR code appears. If the PC is on several networks, pick the one the iPhone is on.
  3. Point the iPhone's Camera app at the code and tap the link.
  4. The first time, Safari says the connection isn't private — the certificate is self-signed, made on your own PC. Tap Show Details, then visit this website.
  5. Tap Start, then allow the camera and motion sensors.

The iPhone is remembered afterwards. Open the page from history, or use Share → Add to Home Screen, and there's no code to scan again. Keep the page open and in front: iOS stops the camera when Safari goes to the background.

Troubleshooting

The phone never connects

Exit MyCam from the tray rather than killing it — a killed companion can leave the phone stuck until you replug it. If you have USB debugging switched on, the phone shows up as accessory + ADB and MyCam can't bind to it; turn debugging off.

The iPhone link doesn't open

Both devices need to be on the same network, and Windows must call it Private. Some guest and office networks block devices from reaching each other entirely.

"Couldn't start its iPhone page on port 47900"

Another program is using that port. The log says which.

The page says the PC is busy

Another phone has MyCam. A phone on the cable always takes priority.

The picture freezes when the phone locks

Expected. The camera stops in the background and the PC waits five minutes for you to come back, showing "Camera paused" to apps in the meantime.

Nothing above helped

MyCam writes a log to %LOCALAPPDATA%\MyCam\mycam.log, including the phone's own messages. Tray → settings → Open log folder. Attach it to a GitHub issue and describe what you plugged in.

Want to build it yourself?

It's MIT. The Android app builds with Gradle, the Windows side with Visual Studio 2022 and CMake, and both test suites run against the same protocol vectors. See the build instructions.
